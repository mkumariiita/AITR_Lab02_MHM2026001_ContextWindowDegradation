# Context-Window Degradation — Position × Citation Study

**Course:** AI Tools for Research (post mid-sem)  
**Student:** Madhukar Kumar · MHM2026001 · IIIT Allahabad  
**Folder:** `AITR_Lab02_MHM2026001_ContextWindowDegradation`

## Problem statement

Does placing gold evidence in the **middle** of a short multi-passage context reduce **citation support** or **evidence coverage** versus begin/end placement, under a frozen free LLM?

**Finding (this protocol):** No — both primary metrics mean **1.00** in all positions (documented negative/null result). Keyword “correctness” varies but is a weak secondary metric.
